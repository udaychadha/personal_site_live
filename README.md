# Uday Chadha — Personal site

The live under-construction page, with a purple accent and dark/light themes.

## Preview locally

Run `python3 -m http.server 8000`, then open http://localhost:8000.

## Publish

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` are published automatically. There are no dependencies or build steps.

Set a custom domain under the repository's **Settings → Pages**, then configure the domain's DNS records at Squarespace. Enable **Enforce HTTPS** when the certificate is ready.

The larger unfinished site is kept separately and is not included here.
